# SDG4 – Skills for Future

## Project Overview
AI-powered Digital Skills Gap Analysis platform
supporting United Nations Sustainable Development
Goal 4, Target 4.4.

## Project Objective
Analyze digital and ICT skills data to identify
skills gaps and support lifelong learning and
employment readiness.

## Project Components
1. Data – Alteryx One
2. Model – Google Colab
3. Utility – Python
4. Frontend – Web Application

## Integration and Deployment
GitHub for team collaboration, testing,
and Vercel deployment.

## SDG Target
SDG 4.4 – Increase the number of youth and adults
with relevant technical and vocational skills for
employment, decent jobs, and entrepreneurship.
